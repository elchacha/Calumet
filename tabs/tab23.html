★ Key features

  • Lists every org known to the Salesforce CLI with alias, username, status, DevHub and default flags, and scratch org information; the list also loads in the background at startup when sf is installed
  • Rename Alias opens a small popup to change the alias of the selected org
  • Set Default User makes the selected org the CLI default user
  • Set Default DevHub is available for a DevHub that is not already the default one
  • Disconnect logs the selected org out of the CLI (not available for scratch orgs)
  • Create Scratch Org opens the creation popup for the DevHub currently selected in the table
  • For a scratch org: Delete Org, Generate Password (shown in an information window) and Auth Scratch Org (opens the Env config window to connect it to Calumet)
  • Every CLI action runs in the background and refreshes the list when it ends; a failure is reported in an error message
