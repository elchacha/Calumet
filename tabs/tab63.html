★ Key features

  • Enter a record Id: the object is found automatically from the Id key prefix.
  • Lists every child relation (objects pointing at the record) and parent relation (lookups on the record).
  • Counts the child records that reference this record, and the records sharing each parent value.
  • Results sorted by record count, largest first: the heaviest locking candidates come on top.
  • If no record matches the Id, the Object type label says so.
  • Cells can be selected and copied.
