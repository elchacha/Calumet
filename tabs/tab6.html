★ Key features

  • Coverage: fetch Apex coverage, filter by band (above 75%, 50 - 75%, below 50%) and export the matching test classes
  • Helper: find the test classes that cover a class or a method, and build a test suite file
  • Limits: compare governor limits consumed by each test (SOQL, DML, callouts, CPU, duration)
  • Results: review the latest run per method, filter by outcome, keep only the latest run, delete results and run all tests
  • Passing package.xml: generate a package.xml of the test classes whose methods all pass
