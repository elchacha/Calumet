Everything else logged in from where it always logs in. The four mixed accounts are a finding in themselves: one credential used both by a person and by a program means the audit trail can no longer attribute what it did.
Salesforce keeps login history for a limited window and then destroys it. Calumet collects one file per day and keeps a rolling year in a ZIP on the org, so the baseline outlives what the platform retains. Collected days are the denominator — a window with three files is never divided by seven.

★ Key features

  • Daily collection into a rolling one-year archive — the history survives the platform's retention.
  • Human / machine / mixed classification from behaviour, never from the licence.
  • Rates per collected day, never a total presented as a rhythm.
  • Click any user count to see the accounts behind it.
  • Configuration changes shown beside the login context of whoever made them.
  • Merging two machines' archives is order-independent: the same day never loses data.
