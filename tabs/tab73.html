★ Key features

  • Search users by name and collect them in a basket; remove one with its × or empty it with Clear all.
  • Retrieve loads the role, permission sets, permission set groups, profile and group memberships of every user in the basket.
  • Single user: every assignment is listed. The Groups tab adds a Membership badge (Direct or Indirect) and a Via column naming the group that grants it.
  • Two users or more: only the differences are shown, one column per user with a check (has it) or a cross (does not have it). The status line counts permission set and group differences.
  • Click a permission set or permission set group label to open its full content.
  • Assign / UnAssign (Permission Sets tab): select the user cells in compare mode, or the rows in single mode. Profiles cannot be assigned. The basket is retrieved again afterwards.
  • Rights tab: effective rights (only the differences when comparing), filtered by text and by category. Each user cell shows how many permission sets (PS) and groups (PSG) grant the right, and whether the profile does; click it to list the sources.
  • The role line shows each user's role, or one shared role when all users have the same.
