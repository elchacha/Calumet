★ Key features

  • Start from a few seed components (manual add), then click Recompute neighbours to walk the dependency graph one hop at a time.
  • Structural neighbours join the Bundle automatically; usage neighbours land in Proposed, grouped by type, for you to Include or Exclude one by one or in bulk.
  • Per-member "Expand neighbours" checkbox, auto-unchecked above a ref threshold, keeps widely-used utility classes from flooding Proposed.
  • Types filter hides noisy node types from Proposed (saved per org).
  • Live package.xml preview, plus a list of members that cannot be mapped to a package type.
  • Generate package + retrieve writes package.xml and a brief into an AI session folder and runs a real metadata retrieve.
  • Requires a full licence and a dependency graph built for the org.
