Simplified interface: when it is switched on, the left panel keeps only the project label, a Validate button (blue), a Deploy button (green), an All Tests checkbox, then the Deployment reason and Comment block. The manage-package buttons and the other options are hidden.

★ Key features

  • Validate, deploy, or run tests then deploy the current project package, with or without all local tests
  • Package, destructive pre and post tabs show every metadata type and member to be deployed or deleted
  • Preview changes, View Deploy Code, View Package and postDeploy information before you commit
  • Deactivate before deploy and Reactivate handle items that must be switched off in the org first
  • Profiles tab filters the profiles to deploy (*, All, None) and lets you edit and save a profile
  • Test tab keeps the test classes to run and saves them to, or loads them from, the project
  • Missing tab flags package.xml members without a file, with a Clean button
  • Api Version and ApiVersion > 66 tabs warn about old components and about components crossing API 66 against the target org
  • Zip selector reuses a package retrieved earlier for the project
