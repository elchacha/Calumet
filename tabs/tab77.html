★ Key features

  • Five guided steps — Config, Objects, Prepare, Export and Import, with the optional Automation and Clean tabs; the Tutorial and How To buttons walk through them.
  • Named configurations — create, clone and switch between configurations, each with its own source/target pair, main path and start query.
  • Three query modes — Basic (parents and children up to Max depth), Single query, or Full copy.
  • Dependency traversal — the traversal plan lists every query to run, in import order; the Report shows anything the plan cannot reach.
  • Per-query limits — Add Limits or edit the Limit column; a limit applies per query, and limits can be saved and reloaded.
  • Count Records dry run — estimate volumes without writing a CSV and spot failing queries through the red Failed links.
  • Check IDs / Check Users — verify parent Ids and user counterparts before importing.
  • Import with remapping — parents first, every record Id remapped; error files say which record was rejected and why, and Retry Failed re-imports only those.
  • Automation muting — disable flows, triggers, process builders and workflow rules on the target before the import, and restore them afterwards from a backup.
  • Clean — delete imported records from the target, optionally within a Created after / before window.
  • Community Users and debug tabs — shown only when the matching Config option is ticked.
