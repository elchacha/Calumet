★ Key features

  • One path as the only navigation, with Previous / Next and a green check on finished steps; the band names the active config, source and target, and flags a production org in red
  • Export records from a source org by dependency traversal, from a single start query, and import them in order with automatic Id remapping
  • Objects: relation filters, needed-objects view, traversal tree, ignore profiles, and a question for heavy objects such as EmailMessage
  • Optional Masking: personal data replaced by made-up values as the CSV files are written
  • Mute the target's automations when the export starts, restore them after the import
  • Picklist preflight and production warning before Import; optional Clean to restart from a known state
