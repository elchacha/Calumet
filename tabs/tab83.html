★ Key features

  • Consumes the graph, never the org — reads the Tab 82 dependency-graph cache to produce a deterministic, offline result; no SOQL, no Tooling calls.
  • Scored debt register — findings weighted Critical (×8) / Important (×4) / Watch (×2) / Info (×1) into a single org debt score, with severity cards, top objects at risk and a category breakdown.
  • Five finding categories — dead code (dead Apex classes/methods), field overloading (multiple automations writing one field), dormant model (objects modelled but never used), permission-set sprawl, and security/access.
  • Per-finding status tracking — Open / Investigating / Confirmed / Deferred / Resolved saved locally and preserved across regenerations.
  • Four-domain state of play — custom-object inventory + centrality + an Object Health table, automation dependencies, integration touchpoints (named credentials), and a dead & dormant summary.
  • AI hand-off — JSON export for prioritisation, a generated enrichment prompt with a Copy button, and an AI brief that writes brief.txt and opens the folder for a CLI/agentic LLM.
  • Embedded viewer + browser — toggle Debt register / State of play inside the app, or open either document in your default browser.
