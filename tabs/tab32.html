★ Key features

  • Search reloads every scheduled job of the org and stamps the time of the load next to the counter.
  • Type pills (Apex + Batch + Flow by default, then Apex Class, Batch Job, Schedule Flow, Dashboard, Report, Report Notification, Others) show how many schedules each type holds; one pill is active at a time.
  • Text filter on job name, target and submitter; the counter reads "n of N schedules".
  • Ten columns: job name, type badge, target, namespace, submitter, started, next run, readable schedule, raw cron expression and number of times triggered.
  • Rows tinted orange have never been triggered; grey rows have no next run.
  • Kill schedule selected aborts every selected job with System.abortJob() through anonymous Apex, then reloads the list.
  • Double-click a Schedule Flow row to open it in Flow Builder.
