★ Key features

  • One verdict per method or class: DEAD CLASS, DEAD, DOORWAY, SUSPECT, DECL or USED, each with the evidence (callers, declarative references, test-only flag).
  • Sandbox: reads the Symbol Tables of the org's classes; the classes must compile. Optional recompile and include testClasses.
  • Production: Symbol Tables are read read-only from the org's already-compiled classes, but triggers cannot be analysed.
  • Results are grouped by class (click a class header to collapse it); click a column header to sort.
  • Filter by status, by type, or with the free-text filter; hide false public method removes methods only used inside their own class.
  • Double-click a row to open the class in your editor at the method's line.
