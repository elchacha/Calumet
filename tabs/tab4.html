★ Key features

  • Extract all metadata modified in the org between two dates and times
  • Restrict results to your own modifications or to a named user
  • Exclude managed-package metadata to focus on custom development
  • Conflicts tab: items also modified by someone else in the same period
  • Custom Settings, Profile and Layout Assignment changes in dedicated tabs, with old and new values
  • Optionally include EmailTemplate, Report and CustomMetadata modifications
  • Open the generated CSV file at any time with "Open csv file"
  • Choose Metadatas popup to build or extend a package.xml from the detected items
  • Use Cache to reuse a previously fetched metadata snapshot instead of calling the org again
  • A progress bar and step line track the extraction; a log report opens only if a problem occurred
