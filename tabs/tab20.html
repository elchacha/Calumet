★ Key features

  • Display reads every governor limit of the connected org in one click
  • Used, Remain and Max values for each limit, plus the percentage consumed
  • Type column groups limits by family (Platform, Storage, Streaming, Email, Workflows, PE, PE-CDC...)
  • Delay column tells when the headroom resets (Daily, Hourly, Monthly)
  • Hide unused is switched on after each Display, so only limits already consumed are listed; untick it to see them all
  • The API call-out counter of the main window is refreshed after each Display
