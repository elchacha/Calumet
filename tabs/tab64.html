★ Key features

  • Profile sub-tab: compare two profiles, the second one possibly in another org; reuse cached files; export the first profile as XML.
  • Permission Set sub-tab: compare two permission sets; reads the Tab54 permission set cache when available.
  • Profile vs Permission Set sub-tab: see what a permission set adds, modifies and shares with a profile.
  • One result table with status filters, permission category list, and a Filter box (use ; for AND).
  • Profile sub-tab only: select rows and build a deployment package A to B or B to A; hide AppExchange entries; hide rows with Delete.
