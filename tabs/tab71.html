★ Key features

  • Three recommendations: Safe to Deactivate (blue), Review (orange), Keep (green), shown as a badge and a light row tint.
  • Configurable inactivity period: number of days, 90 by default. A non-numeric value raises an alert.
  • Two exclusive pill filters: Status (All / Active / Inactive, Active by default) and Show (recommendation). Each group's counts reflect the other group's selection; no re-query needed.
  • Immediate license savings: share of active users flagged Safe to Deactivate (inactive users do not consume a licence).
  • Roles, Activity and Decision columns: wrapped text explaining the signals behind each recommendation.
  • Local cache: the last result is reloaded when the tab opens, with its date shown at the top right. The button reads Start Analysis until a first run, then Refresh.
