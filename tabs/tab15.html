★ Key features

  • Read all org profiles in one click; Use cached values re-uses the last read for a fast restart
  • Filter the profile list by name, or keep only profiles that have active users
  • Tick two or more profiles: the comparison page builds itself and refreshes on every tick
  • Only rows where the profiles differ are listed; identical settings are left out
  • Category buttons (All, Global, Object, Field, Others) with a count on each, plus a section list with its own search
  • Row filter, sortable Name / Type / Distinct columns, one column per profile
  • Click a profile header to use it as the reference instead of the most common value
  • Export JSON writes the differing rows for an LLM or other tooling
