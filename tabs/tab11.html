★ Key features

  • Extract the Setup Audit Trail for a date range; the result is cached locally per org, and the status line shows what the cache covers.
  • Sync history keeps the audit trail and the login history in the org's Files, one file per month, so history older than Salesforce keeps is not lost and every machine gets it.
  • Category pills (exclusive, with live counts), a Show noise box and an Internal pill (changes made by Automated Process or an empty user, hidden by default).
  • Text filters on Action, User, Section and Display, applied as you type.
  • Unresolved fields lists custom field lines whose object or field name could not be determined.
  • Clear cache deletes the local copy; history beyond 180 days is then lost unless it was synced.
  • Double-click a row for the full detail of the change.
