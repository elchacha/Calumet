★ Key features

  • Extract reads every profile once; the pills then filter the result instantly, without calling the org again.
  • Scope pills: Custom (default) or Standard. Clicking the active pill again shows all profiles. The Type column appears when the scope is not Custom.
  • Usage pills: No active users (default), Unused, Inactive only, In use. Each pill shows its count.
  • Status badge: Unused (nobody assigned, green row), Inactive users only (orange row), In use (active users still assigned).
  • Columns show licence, creation date, creator and the number of active and inactive users.
  • Select one or more rows, type the replacement profile (autocomplete) and click Delete: remaining users are moved first. The field is mandatory when a selected profile still has users.
  • The button shows the selection size («Delete 2 selected»). If the org refuses some deletions, a popup lists the reasons, and the table is refreshed.
