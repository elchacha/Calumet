★ Key features

  • Search org debug logs by user, status, minimum duration and date range, with optional 30-second auto-refresh
  • Show All, Success or Failed logs with live counts; failed logs are tinted red
  • Open Monitor for a real-time view of new logs; Search in logs finds a text across cached and loaded logs
  • Double-click a log to open it; right-click for download, filtered download, call tree, execution chain, flow steps, 101 errors, limit consumption and debug-only views
  • Compute the real operation and duration of logs from their content
  • Select exactly two logs and compare them before / after
  • Create, edit and update trace flags for a user, Apex class or Apex trigger, with 30mn to 24h duration shortcuts
  • Log cleanup manager and local cache controls (size, open folder, clear)
  • Analyse Soql 101: analyse a local log file for SOQL 101 errors
