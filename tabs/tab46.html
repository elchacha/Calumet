★ Key features

  • Extract unused layouts analyses the selected org; a progress bar with "Loading..." shows while it runs.
  • Only profiles with users and Only active record types (both on by default) decide which assignments count.
  • Reason badge: red Not assigned; orange Inactive record types, Inactive profiles or Inactive RT + profiles. Hover for the detail.
  • The filter box searches object, layout and reason; the counter shows "shown / total unused layouts".
  • Double-click a row to open that object's Page Layouts in Setup. The Created column shows the day; hover for the full timestamp.
