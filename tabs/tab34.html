★ Key features

  • Flows tab: inventory of every flow with version, status, type, trigger, last modifier and trigger object
  • Type badges (All, AutoLaunched, Flow, Workflow, Trigger, Routing, Invokable) filter one category at a time and show a count per type
  • Filter by text, optionally inside the flow metadata; optional Flow Label column
  • Double-click opens Flow Builder, right double-click opens the Setup page
  • Delete key removes selected flow versions after confirmation (blocked on production unless enabled in the global config)
  • Invokable tab maps Apex invokable methods to the flows that call them
  • SubFlows tab lists parent / sub-flow dependencies
