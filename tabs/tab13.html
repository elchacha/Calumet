★ Key features

  • One term, many types — 13 checkboxes feed 14 result types (Apex covers both classes and test classes).
  • Single results page — family filters (All, Code, Declarative, Content and data), a result-type list with hit counts, and a table with the term highlighted.
  • Row filter — narrow the current table; separate terms with ; for “either”. Flows also get status counts.
  • Double-click to open — source files are downloaded and opened locally, flows open in Flow Builder, other rows open in Salesforce.
  • Add to package.xml — select rows and use the green button (or right-click) to add them to a package.
  • Dependency search — what uses a component and what it uses, from the Tooling API, optionally completed with the local Dep Graph (rows marked Graph were missed by the API).
  • Pivot — select a result row and run the dependency search on it directly.
  • Caches — Clear cache forces a fresh extraction; the Dependency tab can reuse the on-disk metadata inventory.
