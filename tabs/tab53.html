★ Key features

  • Searchable type list: type part of a name to narrow the types; picking one displays its records. Managed types are hidden unless Show managed is ticked.
  • Live filter on all columns; separate terms with ; to require all of them. The record count follows the filter.
  • Export all records writes every record to an .xlsx file; Generate empty xlsx file writes only the headers, ready to be filled in to create records.
  • Upsert Values reads an .xlsx file, creates or updates the records, and reports how many succeeded and which rows had issues.
  • Delete Selection and Export Selection appear once rows are selected; Delete or Backspace in the table also deletes the selection.
  • Double-click a row to open that record in Salesforce Setup.
