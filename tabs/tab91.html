★ Key features

  • Reads the dependency graph offline — no query, and the same verdict as the deletion badges elsewhere.
  • Ranks by removal cost: what nothing points at first, then by dependency count.
  • Warns when a candidate looks like a reference table (read, never written, pointed at by others).
  • Excludes standard and managed metadata, and states how many were set aside.
  • Dormancy threshold taken from the distribution, adjustable per org.
  • Produces a removal package, and records the rulings so a rejected candidate stays rejected.
