This tab is disabled until Build work package succeeds in the Delete Helper. It then opens automatically and shows the Ask AI panel pointed at the work-package folder (package.xml, destructiveChangesPost.xml and the deletion brief), so an AI session can validate the plan before anything is deployed.

The panel's content is the shared Ask AI component; its layout is not reproduced here.

★ Key features

  • Per-object record count, last created / modified dates and days inactive, cached per org on disk (Clear cache to requery).
  • Scope pills (Custom unmanaged, Standard, Managed) and exclusive status badges (Active, Stale 6m, Stale 1y, Stale 2y+, Empty) with live counts.
  • Dependencies and Pointed at by columns, each opening a detail popup; likely reference tables are flagged.
  • Tick objects and send them to the Delete Helper, which gives a deletion-safety verdict per candidate.
  • Blockers are split into To delete / To modify / Delete? / Review / Manual; Promote, Force and Find orphans grow the delete set until stable.
  • Build work package writes package.xml and destructiveChangesPost.xml and unlocks the Ask AI tab.
