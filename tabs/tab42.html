★ Key features

  • Profile overrides: tree of applications, overrides and record type / profile assignments, with filters on AppLabel, Name, Object and Profile, plus Expand All / Collapse All.
  • FD badge: number of components not yet Full Dynamic; click it to open the layout view of the page.
  • FlexiPages: every Lightning page with its FD and CL (Classic Layout) badges, an Object filter and a detail panel.
  • Flexi Unused: pages that no app, record page or tab appears to assign.
  • Double-click a row to open the page in Setup; the clearCache option or Clear cache button refreshes the data.
